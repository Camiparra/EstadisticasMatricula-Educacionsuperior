# Carpeta /docs

Espacio para las evidencias e insumos que el Integrante 4 usará para armar el
informe técnico en PDF: capturas de los tableros, notas de los conocimientos
evidentes de cada dimensión, evidencias de ramas/commits/PRs, etc.

Sugerencia de subcarpetas (crear cuando haya contenido):

```
docs/
├── evidencias/       # capturas y exportes de cada tablero
└── conocimientos/    # texto de los conocimientos evidentes por dimensión
```
