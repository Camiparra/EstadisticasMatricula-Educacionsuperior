Cómo preparamos los datos

  1. Cifras legibles. Los valores usan punto para miles y algunos traen decimales con coma (129.516,5); se convirtieron a números.
  2. {{ resumen.filas_duplicadas | miles }} filas repetidas eliminadas. El archivo trae casi todo el periodo {{ resumen.anio_inicial }}–{{ resumen.anio_final - 1 }} dos veces, a veces con el nombre escrito distinto (BOGOTÁ / BOGOTA).
  3. Territorios normalizados. Se completaron los códigos DANE (5 → 05) y se asignó el nombre de cada departamento, porque la columna original trae el código.
